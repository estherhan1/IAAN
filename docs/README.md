# IAAN project page

This folder contains the static SLT 2026 IAAN project page adapted from
[Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).
Only the sections required for this paper are included: title, author names,
links, method, main VoxParadox results, abstract, code instructions and citation.

## Preview

Open `index.html` locally, or serve the repository directory:

```bash
cd docs
python -m http.server 8000
# Open http://localhost:8000
```

## Publish on GitHub Pages

After merging the PR, go to **Repository Settings → Pages → Build and deployment**,
choose **Deploy from a branch**, select **main** and **/docs**, and save.

If GitHub Pages is enabled for this repository, the conventional URL is
`https://estherhan1.github.io/IAAN/`. The URL is **not confirmed as deployed**.
